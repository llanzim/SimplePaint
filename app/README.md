## Sobre o projeto

O SimplePaint é uma aplicação simples de desenho desenvolvida em Java para Android.

O projeto permite realizar desenhos livres na tela e selecionar diferentes cores para os traços.

## Funcionalidades

- Desenho livre na tela
- Seleção de cores
- Branco como cor inicial
- Cores disponíveis:
    - Branco
    - Magenta
    - Verde
    - Azul
    - Vermelho
- Utilização de múltiplas cores no mesmo desenho
- Botão para limpar o desenho
